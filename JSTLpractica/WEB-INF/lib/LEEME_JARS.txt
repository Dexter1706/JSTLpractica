Copie aquí (WEB-INF/lib) estos dos archivos .jar antes de desplegar,
ya que este proyecto NO usa Maven (no hay pom.xml, es JSP puro):

1. mysql-connector-j-8.3.0.jar (o el conector MySQL que prefiera)
   Descárguelo de: https://dev.mysql.com/downloads/connector/j/

2. jbcrypt-0.4.jar (para el hash de contraseñas usado en
   utilidades.jspf -> org.mindrot.jbcrypt.BCrypt)
   Descárguelo de: https://mvnrepository.com/artifact/org.mindrot/jbcrypt

Sin estos dos jar el proyecto compila las páginas pero falla en tiempo
de ejecución al intentar conectarse a MySQL o al hashear contraseñas.
